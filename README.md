# Roamly — Smart Travel Planner

An Angular standalone frontend for discovering destinations, saving favorites, planning trips, tracking budgets, and building day-by-day itineraries. Trip and itinerary data is stored in the browser's LocalStorage.

## Run locally

```bash
npm install
npm start
```

The app runs at `http://localhost:4200`. Destination photography is loaded from Unsplash and DM Sans / Playfair Display are loaded from Google Fonts, so those assets need an internet connection.
